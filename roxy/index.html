CORNELL BOX

The Assistant builds it, the path tracer renders it

about 5 minutes, shown about 13× faster

One paragraph of prompt in, a lit and rendered scene out. Every step the Assistant takes is a logged tool call through the same command layer a script uses, and the whole turn undoes as one entry.

The final frame: 1024 × 1024, 256 samples, denoised. The red and green bleeding onto the white blocks is light that bounced, not painted.

OPENUSD

Pixar's Kitchen_set, imported and rendered

The stage is converted into Roxy's own scene model, hierarchy and all, then the camera moves into the kitchen and the path tracer renders two views of the interior. Sped up, ending on the finished renders.

PROCEDURAL ESCALATOR

One asset, any path

The same escalator becomes a flat walkway, a straight escalator, an S-curve or a spiral, depending only on the path it follows. Steps, wedges, balustrades, handrails and landings all rebuild from that path and seven controls.

THE ESCALATOR’S GRAPH

215 nodes in seven labelled frames

The path is resampled into frames and anchored, one step is modelled, and eleven wedge variants are packed onto the frames. A lighter display branch feeds the viewport and a full-detail branch feeds the render.

WHAT IT DOES

One tool, from first primitive to final frame

01 · PROCEDURAL MODELING

Every shape owns a node graph

Extrude, inset, bevel, array, heightfield terrain with erosion, and a VEX-style wrangle compiled to GPU kernels. Change any node and the shape recooks.

02 · CONTENT LIBRARY

Build once, place many times

Publish a build as a master; instances store only their overrides, and the renderer shares their geometry instead of copying it.

03 · OPENUSD

Imports that report what they lose

Stages come into Roxy's own scene model with up-axis, units and transform conventions resolved at the boundary, and every lossy conversion is counted, not hidden.

04 · SPLATS & MARBLE WORLDS

Captured worlds next to CG

Ingests Gaussian splat captures and World Labs Marble worlds, and composites them with modeled geometry in the same render.

05 · PATH TRACER

Physically based, on the GPU

Principled BSDF with GGX, VNDF sampling and Kulla-Conty energy compensation; physical sky, caustics and displacement, on Metal.

06 · ASSISTANT & SCRIPTING

Ask, script or click: same commands

Claude builds through the commands you would script, with your own API key, and its changes land on the same undo stack as yours.

INSIDE THE APP

Built like the tools it learned from

An outliner, a Details panel, a node editor, a Script Editor and a viewport, all views of the same scene, in the shape artists know from Maya and Houdini.

The UI is a view of the scene, never the owner of it.

One model

Scene and session are one Qt-free model. The outliner, Details panel and node editor are views of it, refreshed from a typed change bus.

One command layer

A gizmo drag, a panel edit, a script and the Assistant all run registered commands, so undo behaves the same for every one of them.

Honest boundaries

Format quirks are resolved at the IO boundary, and dependencies run one way: app → scene → core.
